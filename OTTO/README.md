# OTTO 크롤러

TV, 냉장고, 세탁기를 수집한다. 인기순 화면에서 일반 노출과 광고 위치를 읽고,
Crocotile API에서 같은 판매 옵션의 가격과 스티커 정보를 가져온다.

메인은 카테고리 필터를 통과한 항목 중 상품 ID와 옵션 ID 조합이 다른 300건을
기본으로 남긴다. 베스트셀러는 일반 노출 순서로 최대 100건에 순위를 부여하고,
메인에 포함된 옵션에 그 순위를 기록한다.

저장소 루트에서 아래 명령을 실행하면 목록과 상세 CSV를 생성한다. 실행 단계에
`db`와 `notify`를 포함하지 않으므로 운영 DB 적재와 메일 발송 없이 결과를 볼 수 있다.

```powershell
.\OTTO\run_all.bat --only "listing,targets,full"
```

실행 결과와 단계별 manifest는 `OTTO/{tv,ref,ldy}/data/output/`에 생성되며,
Git은 이 경로를 무시한다. 이 변경을 처음 적용할 때는 `listing`부터 실행한다.

TV의 HDR 소비전력은 선택한 옵션의 판매 페이지에 있는 HDR 항목에서 읽는다.
페이지에서 해당 값을 확인할 수 없으면 출력값을 비워 둔다.
